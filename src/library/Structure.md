## 🤖 AI 활용 기록

### 📌 시도 1

**프롬프트:**
```
java를 더 깊게 탐구하고싶으니. 자바의 중요 개념인 데이터 캡슐화,
클래스, 상속, 추상클래스등... 객체지향언어의 중요한 파트를
실습해보며 체득할 수 있게 한번도 프로젝트를 만들어보지 않았던
초보 단계의 프로젝트의 뼈대를 생성해주고 주석으로 관련 코드에대한
해석을 작성해줘
```
**프롬프트 결과:**

1단계 — 기초 다지기 (1~2주)

아는 내용이면 빠르게 넘기면 됨.

- 변수, 자료형, 연산자
- 조건문 / 반복문
- 배열, 메서드
- 확인 기준: 콘솔에서 간단한 계산기 프로그램 혼자 짤 수 있으면 통과

미니 프로젝트: 콘솔 계산기 (사칙연산 + 나머지)

---

2단계 — OOP 핵심 (2~3주) ← 지금 이 폴더의 목적

- 클래스 / 객체 / 생성자
- [x]  캡슐화 (private + getter/setter)
- 상속 (extends, super)
- 다형성 (오버라이딩, 오버로딩)
- 추상 클래스 / 인터페이스
- 확인 기준: "이걸 왜 클래스로 나눴는지" 설명할 수 있으면 통과

미니 프로젝트: 콘솔 도서관 관리 시스템

- Book, Member, Library 클래스 설계
- 대출/반납/검색 기능
- OOP 4대 원칙을 직접 적용해보는 게 목표

---

3단계 — 자바 핵심 API (2주)

- 컬렉션 (ArrayList, HashMap, HashSet)
- 예외 처리 (try-catch, 커스텀 예외)
- 파일 입출력 (데이터를 파일로 저장/불러오기)
- String 메서드들

미니 프로젝트: 위 도서관 시스템에 파일 저장 기능 추가
