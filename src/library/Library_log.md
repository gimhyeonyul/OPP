### 📌 활용 2

**프롬프트:**
```
 boolean hadIt = member.getBorrowedBooks().stream()                                                                                                                   
                  .anyMatch(b -> b.getBookId() == bookId); 이부분 코드 로직 설명해줘 
```

**알게된 점:**
- 1단계: member.getBorrowedBooks()은 현재 Member가
빌린 책 목록을 가져오는 메서드를 활용한 것이다.
- 2단계: .stream() anymatch를 사용하기위해 작성한 것이다.
- 3단계: .anyMatch(b -> b.getBookId() == bookId)
하나라도 조건에 맞는게 있다면 "true"이고 b -> b.getBookId() == bookId  는 람다식 (익명 함수)
으로 b는 리스트에서 하나씩 꺼낸 Book객체이고 -> 이후의
  b.getBookId() == bookId코드는 현재 꺼낸 객체와 찾는 ID
와 같은지 비교연산을 수행하는 것이다.
