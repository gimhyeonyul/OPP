## 🎯 이 파일에서 구현하려 한 것

- `Book`을 상속(`extends Book`)받는 자식 클래스 구현
- `getMaxBorrowDays()`를 오버라이딩하여 실물책 최대 대출일 14일 반환
- `super(bookId, title, author)`로 부모 생성자 호출
- `@Override` 어노테이션(@)으로 오버라이딩 명시
- `toString()` 오버라이딩으로 `[실물책] 최대14일` 형태로 출력

---

## 🧠 핵심 개념 정리

### 상속 (Inheritance)
- `extends Book` → Book의 모든 필드(bookId, title, author, isAvailable)와 메서드를 물려받음
- PhysicalBook에서 따로 선언하지 않아도 `getBookId()`, `getTitle()` 등 사용 가능

### super()
- 부모 클래스의 생성자를 호출하는 키워드
- 자식 생성자 첫 줄에 반드시 위치해야 함
```java
public PhysicalBook(int bookId, String title, String author) {
    super(bookId, title, author); // Book의 생성자 실행
}
```

### @Override
- 부모 클래스의 메서드를 재정의한다고 컴파일러에게 알림
- 오타로 메서드 이름이 틀리면 컴파일 에러로 잡아줌
```java
@Override
public int getMaxBorrowDays() {
    return 14;
}
```
