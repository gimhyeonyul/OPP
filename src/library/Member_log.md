## 🤖 AI 활용 기록

### 📌 시도 1

**프롬프트:**
```
List, ArrayList, LinkedList 셋의 차이점과
왜 사용되는지 내가 알면 좋은점까지 너가 교수가 되어
학생인 내가 이해할 수 있도록 설명해줘
```

**알게된 점:**
-  List — 인터페이스 (개념/규칙)
   List는 실제로 존재하는 객체가 아닙니다.
- "이런 기능을 반드시 가져야 한다"는 약속입니다.
- List<Book> list = new List<>();이와같이 객체를 생성하는것은 불가능 합니다.
- add(), remove(), get(index), size() 와 같은 List가 정의해놓은 약속들이 존재합니다.
- ArrayList — 배열 기반 구현체로 중간 삽입과 삭제는 느리지만 내부조회가 빨라
이번 미니 도서관프로젝트에 활용될 예정입니다.
- LinkedList — 연결 기반 구현체로 중간 삽입과 삭제는 빠르지만 조회속도가 O(n)으로 
느립니다.

### 📌 시도 2

**프롬프트:**
```
```
borrowedBooks.removeIf(b -> b.getBookId() == book.getBookId());
```

이 코드에서 removeIf는 List의 메서드인거야?
그리고 이 전체 코드가 의미하는 바가 혹시 빌린책들을 전체적으로
비교하면서 삭제해야하는 해당 책ID가 있나 찾는 거야?
```

**알게된 점:**
- removeIf는 Collection이라는 상위 인터페이스의 메서드이다.

**궁금해진 점:**
- Collection은 처음 들어보는 인터페이스인데 설명부탁해

**알게된 점:**
- Collection은 Java 자료구조들의 공통 조상 인터페이스입니다.
- 세 자료구조(List, Set, Queue) 모두 공통으로 가져야 할 기능을 Collection이 정의합니다.
- Collection이 없다면. List용 메서드, Set용 메서드, Queue용 메서드를 전부 따로 만들어야 함.
- Iterable이란? "for-each 문을 쓸 수 있다"는 약속을 하는 Collection의 상위 인터페이스이다.
