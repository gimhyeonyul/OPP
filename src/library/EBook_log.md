## 🎯 이 파일에서 구현하려 한 것

- `Book`을 상속(`extends Book`)받는 자식 클래스 구현
- PhysicalBook과 달리 `fileFormat` 필드를 추가로 가짐 (PDF, EPUB 등)
- `getMaxBorrowDays()`를 오버라이딩하여 전자책 최대 대출일 7일 반환
- `toString()` 오버라이딩으로 `[전자책/PDF] 최대7일` 형태로 출력
- 다형성: `List<Book>`에 EBook도 담길 수 있음

---

## 🧠 핵심 개념 정리

### PhysicalBook과의 차이점
| 항목 | PhysicalBook | EBook |
|------|-------------|-------|
| 추가 필드 | 없음 | `fileFormat` (PDF/EPUB 등) |
| 최대 대출일 | 14일 | 7일 |
| toString 출력 | `[실물책]` | `[전자책/PDF]` |

### 추가 필드가 있는 자식 클래스
- 부모(Book)에 없는 필드를 자식(EBook)이 추가할 수 있음
- 부모 필드는 `super()`로 초기화, 자식 고유 필드는 직접 초기화
```java
public EBook(int bookId, String title, String author, String fileFormat) {
    super(bookId, title, author); // 부모 필드 초기화
    this.fileFormat = fileFormat; // EBook만의 필드 초기화
}
```

### 다형성 (Polymorphism)
- `Library`의 `List<Book>`에 PhysicalBook과 EBook이 함께 담김
- 꺼낼 때 참조변수 b를 Book 타입으로 꺼내도 실제 타입의 메서드가 실행됨
```java
Book b = new EBook(1, "클린코드", "마틴", "PDF");
b.getMaxBorrowDays(); // → 7 (EBook의 메서드 실행)
```
